# moji-counter

文字数カウンター（GitHub学習用）

- Web版：https://bookacco.github.io/moji-counter/
- 全角換算（半角＝0.5文字）を基本に、文字数・原稿用紙換算・上限チェックを表示します。

## Chrome拡張（文字数カウント＆マーカー）

`extension` フォルダがChrome拡張です。

### インストール方法

1. Chromeで `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」→ このリポジトリの `extension` フォルダを選ぶ

### 使い方

- 文章をドラッグで選択すると、選択範囲の横に「〇字」（全角換算）の小バッジが出ます
- そのまま右クリックすると、メニューに「〇字（全角換算）・原稿用紙〇枚 ― 詳しく見る」と表示されます
- メニューを押すと右下に詳細が数秒表示されます（マウスを乗せている間は消えません）
- 「編集画面で開く」を押すと、Web版に文章を貼り付けた状態で開きます
- 計算はPC内だけで行い、文章はどこにも送信しません（すべてのページで動かすため、Chromeの許可表示は「すべてのサイトのデータの読み取り」になります）
- 拡張を入れる前から開いていたタブでは、再読み込み（F5）後に有効になります

### マーカー機能

- 文章を選択すると、文字数バッジの横に「＋マーカー」ボタンが出ます。押すと黄色いマーカーが引かれます
- マーカーはこのPCのChromeに保存され、ブラウザを閉じても次に同じページを開いたときに復元されます
- 画面右端に黄色い目印が付きます。クリックするとその箇所へ移動します
- マーカーをクリック →「✕ マーカーを消す」で削除できます
- **Ctrl+↓ / Ctrl+↑** で次・前のマーカーへ移動します（端まで行くと反対側へ。入力欄の中では無効）
- 画面右上の「📋 件数」ボタンを押すと、ページ内のマーカーを上から順にまとめてコピーします（1行に1件）
- 画面右上の「🗑」でページ内のマーカーを一括クリアします。直後に右下の「元に戻す」で取り消せます
- 消したマーカー（一括・1件ずつとも）はページごとの「ごみ箱」に保管され、右上の「↩ 回数」を押すたびに、直前に消した操作から1回分ずつ復元できます（Ctrl+Zと同じ考え方。1ページ最大200件）
- 同じ場所にマーカーを引き直した場合は新しい方を優先し、二重には重ねません
- 位置は「マーカーの文字列＋前後の文字」で覚えています。記事の本文が書き換えられた場合は復元できないことがあります

### 更新したとき

`extension` の中身を変更したら、`chrome://extensions` でこの拡張の「再読み込み（↻）」を押してください。

## ファイル構成

- `index.html`：Web版の画面
- `extension/count.js`：文字数の計算ロジック（Web版と拡張で共通）
- `extension/manifest.json`：Chrome拡張の設定
- `extension/marker.js`：マーカーを引く・保存・復元・右端の目印
- `extension/content.js`：各ページで選択範囲を数え、バッジと小窓を出す
- `extension/background.js`：右クリックメニュー
